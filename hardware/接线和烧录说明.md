# 参谋电报机 · 接线和烧录（两块 XIAO 版）

两块 XIAO 各插一根 USB 数据线到 Mac：**主箱**一块、**手柄**一块。没有屏幕、没有 ASR PRO。

## 接线

| | 主箱（旧 XIAO） | 手柄（新 XIAO） |
|---|---|---|
| 按键 | 拨打 → D0，挂断 → D1（D2 也认作挂断；你接的是载板 B3） | 壳上两个键：说话 B2 → D1，删除 B3 → D0（B1 → D2 是备用发送键，可拆） |
| 麦克风 | 不用（接了也没关系） | INMP441：WS → D10，SCK → D9，SD → D8，VDD → 3V3，GND → GND，L/R → GND |
| 功放 | MAX98357：BCLK → D3，LRC → D4，DIN → D5，VIN → 5V，GND → GND | — |
| D6 / D7 | 两块板之间的串口线（旧 D6→新 D7、新 D6→旧 D7）+ 共地：现在用不上，留着不动 | 同左 |

扬声器两根线接功放的 + 和 −，负极**不要**接 GND。

## 烧录（每块只要做一次）

| 烧哪块 | 双击 |
|---|---|
| 主箱 | `烧录主箱.command` |
| 手柄 | `烧录手柄.command` |

**第一次**烧某一块时：先在**那块板子**上按住 **B**、点一下 **R**、松开 **B**，再双击对应的文件。烧好以后再改固件就不用按键了，两块都插着也能自动找到对的那块。

烧好后，系统设置 → 声音里会有「参谋电报机 主箱」和「参谋电报机 手柄」两个设备；参谋菜单栏显示「电报机：主箱、手柄已接入」。

## 用法

| 按键 | 作用 |
|---|---|
| 主箱「拨打」 | 接通电台（实时通话） |
| 主箱「挂断」 | 挂断；没在通话时：作废正在录的话 / 打断参谋朗读 |
| 手柄「说话」 | 按住说、松开 → 字放进输入框（窗口浮出来）；**点一下** → 发出输入框里的字；通话中 = 按住对讲 |
| 手柄「删除」 | 输入框有字 = 清空；录音中 = 作废这句；参谋说话时 = 让他停下 |

按键另一脚接 GND 还是 3V3、载板上有没有电阻都行：固件开机时记下每个键“没按”时的样子，之后变了就算按下（所以**插电开机时别按着键**）。

- 参谋的声音从主箱喇叭出来，听你说话用手柄的麦克风。拔掉手柄会自动挂断，不会偷偷换成别的麦克风。
- 软件没开时插上主箱，8 秒后喇叭会说「未连接参谋电报机。请在电脑上打开参谋电报机软件。」
- 参谋开机自动在后台启动，不弹窗口；要看字幕、国策链或改设置，点菜单栏的「参谋」。

## 注意

- 插上后 macOS 可能把电脑的声音（游戏、视频）也切到电报机喇叭。不想要：系统设置 → 声音 → 输出，选回电脑扬声器（参谋的声音照样走电报机）。
- 功放现在从主箱 XIAO 的 USB 取 5V，开大音量时电流可能不够，先小音量用。
