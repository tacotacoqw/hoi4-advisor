# 参谋电报机 · 硬件 ↔ 电脑软件约定（两块 XIAO：主箱 + 手柄）

固件和电脑软件都按这份来。改了任何一条，两边一起改。

## 两块板子（2026-10-06 实际接法）

同一份固件按角色编译：`pio run -e base`（主箱）/ `pio run -e handset`（手柄）。两块都插 USB 连电脑，各自是一个复合设备。

- **主箱**（旧 XIAO）：只上报 DIAL（D0）、HANG（D1）；功放 D3/D4/D5。USB 名「参谋电报机 主箱」。
- **手柄**（新 XIAO）：上报 PTT（D1）、SEND（D2，备用）、DEL（D0）；麦克风 D10/D9/D8。USB 名「参谋电报机 手柄」。
- 按键极性自动认：开机连读 20 次记下“没按”状态（上拉/下拉各读一次：00 平时低 / 11 平时高 / 10 悬空），变成另一种被拉住的状态就算按下；同一状态持续 60 秒改认为“没按”。实测用户载板是“平时低、按下高”（另一脚接 3V3 + 板上下拉）。
- 两板之间 D6/D7 交叉串口线 + 共地：现在不用，固件不碰 D6/D7。
- 序列号 = 芯片 MAC，两块不同；VID/PID 相同（303A:8D01）。电脑端同时连两块，按键带上是哪块；麦克风选“手柄”、喇叭选“主箱”。

## 引脚（单块时的完整表；按角色只用其中一部分）

| 功能 | XIAO 标签 | GPIO | 说明 |
|---|---|---|---|
| 麦克风 WS | D10 | 9 | INMP441 WS（I2S0，接收） |
| 麦克风 SCK | D9 | 8 | INMP441 SCK |
| 麦克风 SD | D8 | 7 | INMP441 SD；L/R 接 GND = 左声道 |
| 功放 BCLK | D3 | 4 | MAX98357 BCLK（I2S1，发送） |
| 功放 LRC | D4 | 5 | MAX98357 LRC |
| 功放 DIN | D5 | 6 | MAX98357 DIN |
| 拨打 SW1 | D0 | 1 | 另一脚接 GND，内部上拉，按下为低 |
| 挂断 SW2 | D1 | 2 | 同上 |
| 手柄 PTT SW3 | D6 或 D2 | 43 / 3 | 两个脚都读，另一脚接 GND 或 3V3 都认（轮流开上拉/下拉读两次，读数一样 = 按下）。用户自己的 PCB 上说话键 B1 接 D2、另一脚 3V3 |
| 预留 ASR PRO TX | D7 | 44 | 第二版用，第一版不初始化 |
| Sense 卡槽片选 | — | 21 | 拉高，让 TF 卡槽不占 D8~D10 |

- INMP441：ESP-IDF 5 的 i2s_std 必须 **MSB 对齐（bit_shift=false）**，32 位槽取高 24 位，否则丢符号位；有很大直流偏移，要 80 Hz 高通。
- MAX98357**A**：标准 Philips I2S，16 位或 32 位槽都行；单声道内容左右声道各放一份。不出声时继续送 0（保持时钟），不要停时钟。
- UART0 默认在 D6/D7：控制台不要输出到 UART0。

## USB（复合设备，Mac 免驱）

- 名字：产品名 **「参谋电报机 主箱」/「参谋电报机 手柄」**（声卡在系统里就叫这个），厂商 "Field Voice"。VID 0x303A，PID **0x8D01**，序列号 = 芯片 MAC。
- 声卡（UAC2）：麦克风 1 声道 + 扬声器 1 声道，**48000 Hz / 16 bit**。扬声器带异步反馈端点。
- 串口（CDC ACM）：按键、心跳、调试都走这里（不再要 HID 键盘）。
- 端点：IN 号只能用 1~4（ESP32-S3 同时最多 4 个 IN 端点）。分配：
  音频反馈 0x81、麦克风 0x82、CDC 通知 0x83、CDC 数据 IN 0x84；扬声器 OUT 0x01、CDC 数据 OUT 0x02。

## 串口协议（文本行，`\n` 结尾，UTF-8）

设备 → 电脑：

| 行 | 什么时候发 |
|---|---|
| `HELLO fw=2 name=参谋电报机 role=base|handset` | 电脑打开串口（DTR 置位）后、或收到 `HELLO` 时 |
| `BTN DIAL DOWN` / `BTN DIAL UP` | 拨打键按下 / 松开（消抖 25 ms） |
| `BTN HANG DOWN` / `BTN HANG UP` | 挂断键 |
| `BTN PTT DOWN` / `BTN PTT UP` | 手柄说话键（载板 B2 → D1）：软件按住 ≥0.45 秒算说话、更短算“点一下发送” |
| `BTN SEND …` / `BTN DEL …` | 手柄备用发送键（B1 → D2）/ 删除键（B3 → D0） |
| `# …` | 调试日志（以 `# ` 开头，软件忽略） |

电脑 → 设备：

| 行 | 作用 |
|---|---|
| `PING` | 心跳，软件每 1 秒发一次。设备 3 秒内收到过 PING 就认为「软件在线」 |
| `HELLO` | 让设备再报一次 HELLO |
| `INFO` | 设备回几行 `# ` 日志：电平、欠载次数、按键次数、软件是否在线 |
| `PROMPT` | 立刻播一次「请打开软件」提示音（测试用） |
| `BOOT` | 重启进下载模式（烧录用，和 esptool 的 DTR/RTS 复位序列效果一样） |

## 没连上软件时的提示（代替屏幕）

固件里存一段语音（16 kHz 单声道 16 位 PCM，由软件那边用参谋的声音合成好放进 `src/prompt_pcm.h`）：
「未连接参谋电报机。请在电脑上打开参谋电报机软件。」

- USB 插上后 **8 秒** 内没收到 PING → 从喇叭播一次。
- 软件不在线时按拨打 / 挂断 / PTT → 再播一次（两次之间至少隔 10 秒）。
- 电脑正在往扬声器送声音时不播（不和电脑的声音混在一起）。
- 功放没接 5V 时自然听不见，不影响别的功能。
